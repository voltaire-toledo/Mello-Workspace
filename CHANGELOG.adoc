=== ⌨️ Detailed Feature Breakdown

==== 📝 QuickNote MD (WebView2 Markdown Scratchpad)
* **WebView2 & Marked.js Integration (`plugins/QuickNoteMD/`):**
** Replaced legacy native GUI with an embedded Microsoft Edge WebView2 control rendering `assets/editor.html` using Marked.js.
** Seamless two-way asynchronous IPC bridge between AutoHotkey v2 and WebView2 (`WebView2.ahk`, `Promise.ahk`, `ComVar.ahk`).
** Bundled 32-bit and 64-bit `WebView2Loader.dll` for portable out-of-the-box operation.
* **Editing & View Modes:**
** kbd:[Win+Ctrl+M] / kbd:[Win+Alt+M] – Summon or dismiss floating scratchpad (auto-focuses input upon opening).
** kbd:[Alt+V] – Toggle between interactive Edit mode and rendered, read-only Markdown View mode.
** kbd:[Esc] – Hide the scratchpad without losing note content.
** Markdown shortcuts: kbd:[Ctrl+B] (bold `****`), kbd:[Ctrl+I] (italic `**`), and kbd:[Ctrl+Shift+C] (inline code ````).
** Clipboard Image Pasting: Paste images directly from clipboard (kbd:[Ctrl+V]) to embed as Markdown data URIs.
* **Theme Overrides, Transparency & Hover Controls (TASK-4 & TASK-18):**
** Tray context menu theme selector supporting *Auto (Follow System)*, *Light Theme*, and *Dark Theme*, persisted to `%APPDATA%\Mello-Workspace\QuickNoteMD\window.ini`.
** Dynamic window opacity adjustment using kbd:[Alt+WheelUp] and kbd:[Alt+WheelDown] (25%–100%) during active focus or hover, with real-time status bar counter (`#% tr`).
** Auto-dimming: Scratchpad automatically reduces opacity by 20% when unfocused (`WM_ACTIVATE`) and restores configured opacity when reactivated.
** Live font zoom adjustment using kbd:[Ctrl+WheelUp] and kbd:[Ctrl+WheelDown].
** Dynamic geometry retention across summon/hide actions with minimum window bounds (320x240) and starting defaults (800x600).
** High-resolution DPI-aware Markdown icon (`markdown.ico`) applied to window titlebar and taskbar.

==== 💻 Expanded ThisPC Diagnostics & Hardware Telemetry (TASK-3)
* **Comprehensive Metrics Dashboard (`lib/help_about.ahk`):**
** **Motherboard / Baseboard:** Manufacturer, Product model, and Serial Number.
** **Memory (RAM):** Total installed physical RAM calculated dynamically via WMI `Win32_PhysicalMemory`.
** **Network Adapters:** Enabled adapter descriptions, physical MAC addresses, local IPv4/IPv6 addresses, and Default Gateway.
** **External IP:** Asynchronous on-demand external/public IP lookup to prevent GUI initialization latency.
** **Battery & Power:** Battery charge percentage, charging/AC line status, and power chemistry.
** **System Uptime:** Human-readable system boot time and elapsed uptime.
* **UI & Typography Polish:**
** Dedicated copy buttons next to all telemetry fields using the `_GuiControlObj.Gui` reference pattern.
** Modernized typography utilizing Segoe UI Variable with clean, unbolded data fields.
** Widened help dialog layout to 800px for optimal data display across all 6 tabs.

==== ⚡ Dynamic Terminal Resolution & Fallback Cascade (TASK-7)
* **Path-Agnostic Discovery (`lib/app-automate.ahk`):**
** Resolved `LaunchTerminal` failures when `wt.exe` is absent from system `PATH`.
** **Tier 1:** Standard `wt.exe` execution via `PATH`.
** **Tier 2:** Dynamic discovery via COM `shell:AppsFolder` searching for registered instances ("Terminal", "Windows Terminal", "Terminal Preview") without hardcoded absolute paths or package GUIDs.
** **Tier 3:** Tiered shell fallback cascade launching `pwsh.exe`, `powershell.exe`, or `A_ComSpec` (`cmd.exe`).
** Full support for elevated Administrator terminals (kbd:[Ctrl+Alt+Shift+T] and arpeggio kbd:[Alt+Win+O] -> kbd:[T]).

==== 🔔 Disable Startup Sound Tray Option (TASK-10)
* **Audio Preference Management (`lib/traymenu.ahk`, `Mello-Workspace.ahk`):**
** Added *Disable Startup Sound* toggle item to the system tray menu.
** Persists mute setting in HKCU registry (`HKCU\Software\Mello-Workspace\DisableStartupSound`).
** Dynamically updates tray menu item icon (`checked.ico` / `unchecked.ico`) upon toggle.
** Suppresses startup chime playback (`assets/sounds/start_app.wav`) on script launch and reload when enabled.

==== 🔤 Heavy Line Tree & Diagramming Hotstrings
* **Refined Pseudographics (`lib/hotstrings-mgmt.ahk`):**
** Upgraded tree and box hotstrings to heavy-weight Unicode lines:
*** `:|` -> `┃` (vertical), `:-` -> `━` (horizontal), `:+` -> `╋` (cross).
*** `:|-` -> `┣` / `:|--` -> `┣━━` (branch right), `:|_` -> `┗` / `:|__` -> `┗━━` (corner bottom-left).
*** `:-v-` -> `┳` (T down), `:-^-` -> `┻` (T up), `:-|` -> `┫` (branch left).
*** `:r` -> `┏`, `:7` -> `┓`, `:L` -> `┗`, `:J` -> `┛`.
*** `:|-d` -> `┣━━📁` (directory branch), `:|-f` -> `┣━━📄` (file branch).
*** `:Ld` -> `┗━━📁` (terminal directory node), `:Lf` -> `┗━━📄` (terminal file node).

==== 📚 AsciiDoc Documentation Architecture
* **Documentation Overhaul:**
** Replaced legacy `README.md` with rich AsciiDoc `README.adoc` featuring collapsible sections, badge matrices, hardware routing tables, and architecture diagrams.
** Added structured `CHANGELOG.adoc` following Keep a Changelog specifications.

==== 🎭 Kaomojis & Character Additions

==== 📅 Dynamic Date & Time Replacements
* **System Clock Macro Expansions:**
** `:yyyy` – Expands current 4-digit year (e.g. `2026`).
** `:yy` – Expands current 2-digit year (e.g. `26`).
** `:mm` – Expands current 2-digit month (e.g. `07`).

=== ⌨️ Detailed Feature Breakdown

==== Core Hotkeys & System Controls
* **Script Lifecycle Controls:**
** kbd:[Ctrl+Alt+Win+S] – Toggle script suspension with tray icon state change.
** kbd:[Ctrl+Alt+Win+R] – Reload and reinitialize Mello-Workspace.
** kbd:[Ctrl+Alt+Win+E] – Open script in default editor.
* **System Actions & Navigation:**
** kbd:[Ctrl+Alt+Win+F1] – Open the interactive *Help & About* dialog.
** kbd:[Ctrl+Alt+Win+F2] – Open the AutoHotkey documentation (`AutoHotkey.chm`).
** kbd:[Ctrl+Alt+Win+F3] – Launch AutoHotkey *WindowSpy*.
** kbd:[Ctrl+Alt+Win+F12] – Trigger system sleep mode via `powrprof.dll`.
** kbd:[Ctrl+Alt+Win+F] – Open the active Mello-Workspace folder in File Explorer.
** kbd:[Ctrl+Win+F] – Open Documents directory in File Explorer.
** kbd:[Win+F] – Remap Windows Feedback shortcut to open user home folder.
* **Tenkeyless (TKL) Keyboard Navigation:**
** kbd:[RCtrl+Up] / kbd:[RCtrl+Down] – Send `PgUp` / `PgDn`.
** kbd:[RCtrl+Left] / kbd:[RCtrl+Right] – Send `Home` / `End`.

==== 🪟 Window & Mouse Management
* **Dynamic Window Resizing & Snapping:**
** Multi-monitor aware window grid snapping (Left, Right, Full, Top/Bottom Halves, Quarters).
** Fine-grained border expansion and contraction (`ResizeWindowBorders`).
** Monitor edge snapping (`ExtendToMonitorEdge`).
* **Middle-Click Mouse Gestures:**
** Gesture recognition on kbd:[Ctrl+Alt+Win+MButton] drag:
*** Up: Toggle maximize/restore.
*** Down: Toggle Always-on-Top pinning.
*** Left / Right: Snap to left / right screen half.
*** Diagonals: Snap to top-left, top-right, bottom-left, bottom-right quadrants.
*** Click without movement: Minimize active window.
* **Dynamic Mouse Pointer Scaling (`cursor-mgmt.ahk`):**
** kbd:[Ctrl+Alt+Win+\]] – Increment cursor size in 16px steps (clamped up to 256px).
** kbd:[Ctrl+Alt+Win+\[] – Decrement cursor size.
** Immediate visual feedback via transient ToolTip.

==== 🔤 Hotstrings & Text Automation
* **Box Drawing & Diagrams:**
** `:box` – Quick ASCII/Unicode rounded box.
** `##tbox-thick##` – Double-line heavy Unicode box.
** `:rtable` – Formatted rounded data table template.
** Directory tree builders: `:tree-add-dir` (├──📁), `:tree-add-file` (├──📄), `:tree-end-dir` (└──📁), `:tree-end-file` (└──📄), `:tree-extend` ( │).
* **Symbols & Formatting:**
** ANSI directional arrows (`:arrowleft`, `:arrowright`, `:arrowup`, `:arrowdown`).
** Monospaced keycap symbols (`:keycmd`, `:keyalt`, `:keyctrl`, `:keyshift`, `:keywin`, `:keytab`, `:keyenter`, `:keybackspace`, `:keydel`).
** Kaomoji emoticons (`:shrug`, `:tableflip`, `:fuckoff`, `:idk`, `:ohshit`).
** Common emojis (`:fire`, `:check`, `:warning`, `:star`, `:lightbulb`, `:zap`, etc.).
** Dynamic date stamps: `:yyyy`, `:yy`, `:mm`, `:dd`.
* **User Customization Support:**
** Seamless inclusion of user hotstrings and overrides from `custom/.mslrc.ahk`, `.mslrc.ahk`, or `%AppData%\.mslrc.ahk`.
** Auto-generation of user-customizable `custom/_custom_functions.ahk` stub.

==== 🎵 Arpeggios & Modal Launching
* **Modal Keystroke Launching (`arpeggios.ahk`):**
** Multi-key sequence trigger with HUD splash feedback.
** kbd:[Alt+Win+P] – Window Management Mode modal overlay with live interactive arrow-key moving, resizing, and numpad grid snapping.
* **Application Automation (`app-automate.ahk`):**
** Double-tap kbd:[RCtrl] – Launch Calculator.
** kbd:[Ctrl+Alt+T] – Launch or focus Windows Terminal.
** kbd:[Ctrl+Alt+Shift+T] – Launch elevated (Admin) Windows Terminal.
** Universal `shell:AppsFolder` launcher with UAC-aware privileges.

==== 🖥️ System Tray Menu & ThisSystem.Info
* **Context-Aware System Tray:**
** Dynamic tray icons reflecting session states (Standard, Remote Desktop / RDP session, macOS keyboard mapping mode, Paused/Suspended).
** Direct shortcuts to reload, edit, open directory, inspect WindowSpy, or view script lines.
** Start Menu startup integration toggle (`ToggleRunAtStartup`).
* **Interactive Help & About Dashboard (`help_about.ahk`):**
** Tabbed graphical interface displaying cheat sheets for hotkeys, hotstrings, window commands, and arpeggios.
** **ThisSystem.Info tab:** Live system metrics gathering (Host Name, Current User, OS Version, Architecture, CPU details, RAM capacity, Uptime) with one-click clipboard copy buttons.

==== 🌐 Remote Desktop & Cross-Platform Compatibility
* **macOS to Windows Remote Desktop Remaps:**
** Automatically adapts common macOS shortcuts inside RDP / Hyper-V sessions:
*** kbd:[Cmd+Shift+P] -> kbd:[Ctrl+Shift+P] (Command Palette)
*** kbd:[Cmd+I] -> kbd:[Ctrl+I] (Italics)
*** kbd:[Cmd+B] -> kbd:[Ctrl+B] (Bold)
*** kbd:[Cmd+Y] -> kbd:[Ctrl+Y] (Redo)
*** kbd:[RAlt+Arrows] -> `PgUp`/`PgDn`/`Home`/`End` mapping.

==== 📦 Automated Deployment & PowerShell Engine (`Mello-Workspace.ps1`)
* **Dual Execution Modes:**
** **URL / Web Bootstrap (`Install-FromUrl`):** One-liner installation from PowerShell. Automatically downloads and unpacks MWS, manages backups, fetches official AutoHotkey v2 binaries from GitHub Releases, configures executables, and installs Start Menu shortcuts.
** **Local Repository Runner (`Run-FromLocal`):** Prepares dependencies in-place within the cloned workspace and creates/refreshes desktop and Start Menu shortcuts.
* **Safe State Management:**
** Automated timestamped directory backups (`backup-YYYYMMDD_X`) before upgrades.
