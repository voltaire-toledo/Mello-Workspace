Mello-Workspace (MWS) is an unobtrusive background companion that bridges the gap between your intent and your actions. It is built to keep you in the flow by eliminating repetitive clicks, organizing your desktop clutter, and providing consistent keyboard muscle memory across all your daily apps.

Whether you are a developer, power user, or managing ADHD focus and time blindness, MWS reduces friction so you can focus on the work that matters.

== 🌟 What Mello-Workspace Does for You

* **Perfect Window Snapping:** Stop wrestling with window borders. Press kbd:[Alt+Win+P] to turn your Numpad into a spatial 9-zone screen controller. One tap snaps your window to the exact half, quarter, or center of your display.
* **Floating QuickNote MD Scratchpad:** Need to jot down a quick idea or paste an image? Press kbd:[Win+Ctrl+M] or kbd:[Win+Alt+M] to summon an instant Markdown scratchpad powered by Edge WebView2. It auto-dims when you switch tasks and remembers your notes automatically.
* **Smart Text Automation:** Never retype the same templates or hunt for characters. Type simple triggers like `:yyyy` for the current year, `:rtable` for a formatted table, or `:shrug` for `¯\_(ツ)_/¯`.
* **Adaptive Mouse Buttons:** Using a multi-button mouse like the Logitech G502X? MWS dynamically adapts your extra buttons to the focused app (e.g., code indenting in VS Code, navigation in Notion, or tab switching in Edge).
* **Calm & Accessible:** Lose your cursor on multiple 4K monitors? Scale it up instantly with kbd:[Ctrl+Alt+Win+\]]. Need to pause all shortcuts for gaming? Suspend MWS with a single keystroke.

[TIP]
====
MWS operates quietly in the Windows background without requiring admin rights for daily usage. It dynamically discovers your installed tools without hardcoded paths.
====

== 🚀 One-Step Installation

The easiest way to get started is with our automated PowerShell installer. It downloads the required files, configures AutoHotkey v2 into a self-contained folder, creates your Start Menu shortcut, and launches MWS immediately.

[source,powershell]
----
# 1. Open PowerShell and run this single command:
irm https://raw.githubusercontent.com/voltaire-toledo/Mello-Workspace/main/Mello-Workspace.ps1 | iex <1>
----
<1> Downloads the latest release, creates safe backups of existing settings in `%LOCALAPPDATA%\Mello-Workspace\backup-*`, sets up Start Menu shortcuts, and starts the workspace.

[NOTE]
====
MWS installs safely into `%LOCALAPPDATA%\Mello-Workspace` without polluting system directories. A Start Menu shortcut is automatically registered under `Programs > Mello`.
====

=== 🛠️ Advanced & Developer Setup
[%collapsible]
====
If you prefer managing the repository via Git or contributing to features:

[source,powershell]
----
# 1. Clone the repository
git clone https://github.com/voltaire-toledo/Mello-Workspace.git
cd Mello-Workspace

# 2. Run locally (provisions portable AutoHotkey binaries into ahkbin/)
.\Mello-Workspace.ps1 <1>

# 3. Optional: Initialize developer pre-commit hooks and tests
.\scripts\setup-dev.ps1 <2>
# Or use Taskfile:
task setup
----
<1> Detects repository context, downloads portable AutoHotkey v2 into `ahkbin/` if missing, and creates local Start Menu shortcuts.
<2> Configures developer tooling, git hooks, and user custom function templates.

=== 📝 QuickNote MD (Floating Markdown Scratchpad)
[%collapsible]
====
QuickNote MD provides a distraction-free scratchpad built directly into Windows using Microsoft Edge WebView2 and Marked.js.

* **Summon Instantly:** Press kbd:[Win+Ctrl+M] or kbd:[Win+Alt+M] from any app. The scratchpad appears immediately with the text cursor focused.
* **Edit <-> Preview:** Press kbd:[Alt+V] to toggle between live Markdown editing and rendered HTML preview.
* **Hide Window:** Press kbd:[Esc] to hide the window without losing your note.
* **Fast Formatting:**
** kbd:[Ctrl+B] – Wrap text in `**bold**`.
** kbd:[Ctrl+I] – Wrap text in `*italic*`.
** kbd:[Ctrl+Shift+C] – Wrap text in inline `code`.
* **Clipboard Image Paste:** Press kbd:[Ctrl+V] while an image is on your clipboard to instantly embed it inline.
* **Dynamic Opacity & Hover:**
** Reduces opacity by 20% when unfocused so it never obscures your primary work.
** Adjust opacity using kbd:[Alt+WheelUp] and kbd:[Alt+WheelDown] (25%–100%) while active or simply hovering over the window. Live opacity is displayed in the status bar (`#% tr`).
* **Theme Modes:** Right-click the tray icon to choose between *Auto (Follow System)*, *Light*, or *Dark* theme.
* **Auto-Save:** Notes and window positions are saved automatically to `%APPDATA%\Mello-Workspace\QuickNoteMD\`.
====

=== 💻 System Tray & ThisPC Diagnostics Dashboard
[%collapsible]
====
MWS lives quietly in your system tray, featuring an adaptive icon that shows your current session mode (Standard, Remote Desktop / RDP, macOS keyboard mapping mode, or Paused).

image::docs/assets/mws/PowerToys_Paste_20260222230648.png[MWS Help and Telemetry UI,520,align=center]

* **Tray Menu Features:**
** **Launch at Startup:** Automatically runs MWS on user logon via registry Run key (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
** **Disable Startup Sound:** Mutes the startup audio chime, saved in `HKCU\Software\Mello-Workspace`.
** **Using Mac Keyboard Layout:** Remaps macOS Command shortcuts inside remote sessions.

Hit kbd:[Ctrl+Alt+Win+F1] to open the **Help & About** dashboard:
* **Live System Metrics:** View Motherboard model, CPU cores, RAM capacity, Network adapters (MAC, Local IP, Gateway), on-demand Public IP, Battery status, and Uptime.
* **One-Click Copy:** Click the copy button next to any field to copy its value directly to your clipboard.

== ⚙️ Make It Your Own

MWS is designed so you can add your own personal shortcuts and hotstrings without editing core files or creating merge conflicts.

[source,autohotkey]
----
; Add your personal customizations to custom/_custom_functions.ahk or custom/.mslrc.ahk

; Example 1: Add a personal hotkey to launch your favorite tool <1>
^!j::MsgBox("Custom workspace action executed!")

; Example 2: Add an email expansion snippet <2>
:*::myemail::developer@domain.com
----
<1> Custom hotkey triggers an AutoHotkey action without modifying core files.
<2> Instantly replaces `myemail` with your actual email address anywhere you type.

[IMPORTANT]
====
Always put your personal macros in `custom/_custom_functions.ahk` or `.mslrc.ahk`. These files are ignored by Git, ensuring your customizations remain intact when updating MWS.
====
