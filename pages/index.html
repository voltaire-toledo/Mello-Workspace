Core Window Engine

Sub-millisecond window layout snapping

Traditional Windows Snap frequently trips up when multi-monitor scaling, edge detection, or slow animations kick in. Mello's window engine bypasses explorer animations and calculates precise bounding boxes using direct Win32 coordinate transforms.

  • Zero border overlap: Computes true client rectangles excluding invisible DWM drop shadows.
  • Multi-monitor aware: Snaps and traverses monitors regardless of asymmetric resolution configurations.
  • Excluded Windows guard: Never snaps or distorts floating dialogs, Task Manager, or games.

Registry & Input Architecture

Reclaiming the sacred Hyper Key from the OS

Keyboards with an Office key or users pressing Ctrl+Alt+Shift+Win are routinely interrupted by Windows launching Microsoft 365. Mello neutralizes this hijack at the user-registry level without requiring Administrator elevation.

  • Zero UAC prompts: Executes completely in HKCU; no admin elevation or security alerts.
  • Reversible at any time: Easily toggled via the Mello tray menu with real-time checkbox status.
  • Swallows chord triggers: Chords for Word, Excel, Teams, and PowerPoint are absorbed cleanly.

03 The Engineering Doctrine

Built to last. Built to respect your computer.

01

Composition Root Pattern

Mello-Workspace.ahk is the sole entry point. Modules in lib/ remain strictly decoupled, clean, and self-contained. There are no circular dependencies or spaghetti includes.

02

The Window Exclusion Guard

Every single function touching window geometry must pass through IsExcludedWindow(). Fullscreen games, virtual machines, and system dialogs are sacred and never disrupted.

03

Zero Telemetry & Offline First

Your keystrokes, scratchpad notes, and window titles stay completely on your machine. Mello contains zero analytics beacons, zero phone-home routines, and runs completely air-gapped.

04

AutoHotkey v2 Exclusive

Targeting AutoHotkey v2 exclusively eliminates legacy v1 quirks. Native object types, lexical scoping, structured error handling, and clean PascalCase functions ensure high reliability.
