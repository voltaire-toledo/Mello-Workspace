Architecture Overview

Mello-Workspace Architectural Blueprint

A low-cortisol productivity toolkit for Windows targeting AutoHotkey v2 exclusively. Engineered for zero input latency, deterministic geometry, and intentional ergonomic friction.

Core Philosophy

Mello-Workspace eliminates the cognitive friction inherent to modern operating systems. Standard window managers use rubber-band animations, unpredictable snapping heuristics, and OS telemetry. Mello bypasses these layers entirely using native Win32 coordinate transforms and silent protocol intercepts.

Key Axiom: The screen should never argue with your hands. Every chord has a deterministic, sub-millisecond outcome.
Code Architecture

Composition Root & Library Decoupling

Mello-Workspace.ahk is the single composition root. It loads self-contained, loosely coupled modules residing in lib/. 

; Composition Root Pattern in Mello-Workspace.ahk
#Requires AutoHotkey v2.0
#SingleInstance Force

; Pure decoupled module includes
#Include <window-mgmt>
#Include <hotkeys>
#Include <apps-hk>
#Include <traymenu>
#Include <../plugins/SoundSwap/SoundSwap>

Hard Invariants

  • AutoHotkey v2.0 Exclusivity: Legacy v1 syntax or backward-compatibility shims are strictly defects.
  • No circular includes: Modules in lib/ must never include each other directly; orchestration occurs exclusively at the root.
Hardware & Signals

Demystifying Higher Function Keys (F13–F24)

Routing mouse buttons, keypad macros, and secondary tiers into virtual higher function keycodes without shortcut collisions.

Standard software constantly competes for Ctrl, Alt, and Shift combinations. By utilizing virtual keys F13 through F24, Mello-Workspace establishes a dedicated, silent signal plane.

Ergonomic Tiers & Intentional Friction

Tier Keycodes Physical Trigger Design Objective
Velocity Actions F14, F16 Thumb side clicks, wheel tilts Rapid, low-friction operations (tab switching, page stepping).
Guarded Actions F23, F18 G-Shift modifier + reach Intentional posture change to prevent accidental window closure or deletions.
Input Architecture

Office 365 Hyper Key Layer (TASK-25)

Windows Explorer hardcodes the chord Ctrl+Alt+Shift+Win to invoke ms-officeapp:, opening the Microsoft 365 web portal and stealing focus.

Neutralization Mechanism

Mello intercepts the protocol under HKCU:\Software\Classes\ms-officeapp\Shell\Open\Command, replacing the default command with a silent rundll32 no-op executable. 

; AutoHotkey v2 registry neutralization routine
ApplyOfficeKeyNeutralization(enable) {
  cmdKey := "HKCU\Software\Classes\ms-officeapp\Shell\Open\Command"
  try {
    if (enable) {
      RegWrite("rundll32", "REG_SZ", cmdKey)
    } else {
      RegDeleteKey(cmdKey)
    }
  }
}
  • Zero elevation required: Runs cleanly under user scope (HKCU) with no UAC prompt.
  • Hotkeys swallowed: Chords like *#^!p and *#^!w are cleanly absorbed without opening unwanted browser tabs.
Safety Architecture

IsExcludedWindow() Safety Guard

Window management tools often break games, virtual machines, or system dialogs when applying automatic snapping. In Mello-Workspace, every geometric manipulation function MUST invoke IsExcludedWindow() before calculating bounds. 

; Strict pre-commit requirement (Test 5)
SnapWindow(direction) {
  activeHwnd := WinGetID("A")
  if IsExcludedWindow(activeHwnd) {
    return ; Never disrupt excluded window states
  }
  ; Proceed with deterministic coordinate transform...
}
